1. INTRODUCTION 
The rapid advancement of technology has transformed agricultural practices, making 
autonomous robotics and IoT platforms the primary solution for crop management, selective 
spraying, and soil monitoring. These platforms simplify farming operations, reduce chemical 
wastage, and improve food production efficiency. However, traditional farming methods rely 
heavily on broadcast spraying across entire fields, making it difficult to deliver localized crop 
care and leading to soil contamination and environmental toxicity. 
To address these challenges, Agri Rover is developed as an autonomous cyber-physical mobile 
robot specifically for precision agriculture and crop care. The platform enables automated crop 
row guidance, computer vision-based pest and weed detection, directio nal solenoid spraying, 
and electrochemical soil nutrient probing using Raspberry Pi microcomputers and Three.js 3D 
WebGL Digital Twin simulation, providing a scalable, safe, and cost -effective solution for 
agricultural operators. 
1.1 Project Description 
Every harvesting season, agricultural producers face significant crop losses from pest 
infestations and weed competition, yet conventional chemical spraying relies on broad -area 
tractor boom sprayers designed for uniform broadcasting. Farmers are left applying expensive, 
toxic pesticides across healthy and diseased plants alike, with no real -time feedback on soil 
nutrient health or crop status. "Agri Rover" is proposed and built as an autonomous, fresher -
focused agricultural vehicle that closes this gap on bo th hardware actuation and digital 
monitoring sides. 
On the field side, Agri Rover utilizes a heavy -duty 6-wheel skid-steer chassis driven by dual 
BTS7960 43A motor drivers carrying a 5 to 10 liter pesticide tank. An onboard camera feeds 
real-time video to an OpenCV computer vision pipeline, automatically identifying crop rows, 
invasive weeds, and insect pests. Upon detection, directional solenoid valves fire pressurized 
micro-bursts strictly to infected zones, reducing pesticide usage by up to 80%. On the 
monitoring side, an integrated linear actuator lowers an electrochemical probe to log 
georeferenced NPK, pH, and moisture data into a real-time dashboard.

2. LITERATURE SURVEY 
A study of existing agricultural sprayers and recent research on autonomous field robotics was 
carried out to understand current farming practices and their limitations. Popular platforms 
such as tractor boom sprayers and commercial agricultural drones provide general spraying 
but are primarily designed for b road-area broadcasting. Research on edge computing and 
computer vision highlights the benefits of localized chemical actuation, reduced soil toxicity, 
and automated nutrient monitoring. Based on these findings, Agri Rover was designed as a 
cyber-physical v ehicle focused on precision crop care, integrating OpenCV -based threat 
detection and real -time 3D simulation to improve the farming experience for agricultural 
operators. 
2.1 Existing and Proposed System 
Existing System 
General-purpose spraying systems such as tractor-mounted booms and aerial spraying drones 
dominate the current market. They are built to serve large open fields at once, which brings 
three recurring problems for precision crop care in particular. First, chemical application is 
uniform rather than threat -driven, so healthy plants receive the same chemical dosage as 
diseased plants. Second, these platforms give operators little to no visibility into real-time soil 
nutrient levels (NPK/pH) — there is typically no integrated ground probing mechanism. Third, 
most commercial autonomous machines are expensive, proprietary systems that are neither 
designed nor priced for accessible institution-level deployment or digital twin virtual testing. 
Proposed System 
Agri Rover addresses each of the above gaps directly. It restricts its operational scope to row-
crop environments so that every design decision — the skid -steer wheel alignment, the 
OpenCV color segmentation algorithms, the UI teleoperation controls — can be tuned for 
precision targeting. It introduces an automatic, transparent AI threat detection score computed 
the moment a camera frame scans a crop, replacing blind broadcasting with localized solenoid 
valve bursts. It gives operators a real-time status dashboard and automated soil probe sampling, 
reducing chemical pesticide volume by up to 80%. Finally, the entire virtual system is built on

2.2 Feasibility Study 
2.2.1 Technical Feasibility 
All components used in Agri Rover - Raspberry Pi 4, BTS7960 motor drivers, solenoid valves, 
OpenCV, NumPy, RPi.GPIO, HTML5 WebGL, Three.js and OrbitControls - are mature, well-
documented tools, and the development team already has working fami liarity with Python, 
JavaScript, and hardware interfacing. No specialized proprietary hardware is required; the 
application is developed and tested on standard development workstations and deployed to 
Raspberry Pi hardware. The project is therefore technic ally feasible within the time and skill 
constraints of a II-Semester PBL exercise. 
2.2.2 Operational Feasibility 
The end-user workflows - driving via WASD, selecting spray modes (Option 1 Blanket vs 
Option 2 Targeted AI), toggling Lane Lock, and deploying the soil probe - mirror patterns that 
operators easily understand, minimizing the learning curve. The single -page digital twin 
simulator is responsive and requires only a modern web browser, with no client -side 
installation. The system requires no complex dedicated maintenance once configured. 
2.2.3 Economic Feasibility 
Because the control software relies on open -source libraries and affordable off -the-shelf 
microcontroller components, the system incurs minimal fixed cost. The software simulator 
runs entirely offline in -browser at zero operational expense. This makes the project 
economically feasible to build, run and maintain for academic demonstration and field 
deployment.

3. TOOLS AND TECHNOLOGIES USED 
The development of Agri Rover involves the use of modern web technologies, computer vision 
frameworks, and microcontroller hardware drivers to build a secure, scalable cyber -physical 
robot. The frontend digital twin is developed using Three.js and WebGL, while the physical 
hardware controller is implemented using Raspberry Pi OS, Python, OpenCV, and RPi.GPIO. 
These technologies work together to provide efficient motor driving, vision processing, 
solenoid actuation, and telemetry display. 
3.1 React.js / Three.js 3D Web Engine 
The digital twin client dashboard is built using HTML5, CSS3, JavaScript (ES6+), and Three.js 
v0.128.0 with OrbitControls.js for 3D WebGL scene rendering. Three.js was chosen for its 
component-driven 3D structure, lighting and shadow capabilities, and suitability for building 
a fast, browser-based simulation that executes without client-side plugins. 
3.2 Raspberry Pi Controller 
All hardware control logic - motor PWM speed modulation, solenoid valve opening, OpenCV 
frame processing, and soil probe stepping - is implemented as mod ular Python 3.10+ scripts 
(`motor_control_pi.py`, `pesticide_sprayer.py`, `camera_stream.py`). Each script is single -
purpose, stateless, and reads GPIO pin configuration from central definitions, keeping code 
portable across simulation and physical Pi hardware. 
3.3 OpenCV Vision Pipeline 
Real-time video processing is handled by OpenCV 4.x (`cv2`). The vision pipeline converts 
video frames into HSV color space, applies morphological noise filtering, and extracts crop 
row guidelines using Hough Line Transforms. It detects caterpillars (purple mask) and weeds 
(red mask), calculating spatial offsets to trigger directional solenoid valves. 
3.4 Safety & Emergency Shutdown 
Power management and safety lockouts are enforced by the controller loop. If simulated 
battery voltage drops below 12.0V (<= 12%), the system automatically triggers an emergency 
halt, locking motor PWM outputs and closing all chemical valves to prevent brownouts.

• Battery voltage remains above 12.0V during active patrol.

7.2.1 OpenCV AI Threat Detection & Solenoid Control (Python) 
def detect_pests_and_spray(frame, width): 
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV) 
    purple_mask = cv2.inRange(hsv, np.array([130, 50, 50]), np.array([160, 255, 255])) 
    contours_p, _ = cv2.findContours(purple_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE) 
    for c in contours_p: 
        if cv2.contourArea(c) > 150: 
            x, y, w, h = cv2.boundingRect(c) 
            side = 'left' if (x + w/2) < (width / 2) else 'right' 
            pesticide_sprayer.execute_sprayer_logic(rover_is_moving=True, detected_targets=[{'side': side}])

def set_motors(left_speed, right_speed): 
    left_speed = max(min(left_speed, 100), -100) 
    right_speed = max(min(right_speed, 100), -100) 
    pwm_left_f.ChangeDutyCycle(abs(left_speed) if left_speed > 0 else 0) 
    pwm_right_f.ChangeDutyCycle(abs(right_speed) if right_speed > 0 else 0)

function runAutonomousRowFollow() { 
    const dy = targetY - state.y; 
    let angleDiff = targetAngle + steerAngle - state.angle; 
    if (Math.abs(angleDiff) > 0.35) { 
        state.speed = 0.0; // Point turn 
        state.angularSpeed = angleDiff * 0.25; 
    } else { 
        state.speed = 1.0; // Cruise speed 
        state.angularSpeed = angleDiff * 0.18; 
    }

9. CONCLUSION 
Agri Rover demonstrates that a fully autonomous, cyber-physical robotic vehicle — powered 
by Raspberry Pi for hardware control, OpenCV for computer vision threat segmentat ion, 
BTS7960 motor drivers for heavy payload transit, and Three.js 3D WebGL for digital twin 
simulation — can support a complete precision agriculture workflow with zero physical risk 
during initial testing. Framing the system specifically around fresher t echnical innovation 
made it possible to bake in localized solenoid micro -bursts and automated NPK soil probing, 
achieving up to 80% chemical reduction. 
Future enhancements identified during the project include: replacing basic color thresholding 
with lightweight YOLOv8 edge models; adding LoRaWAN transceivers for long -range field 
telemetry; and deploying an automated solar docking station for continuous autonomous 
operations.
